# Dementia Assessment – Feature Extraction & ML Evaluation

This repository contains part of a group project developed in collaboration with an external company,
focused on the automatic assessment of dementia using machine learning techniques.

## My Contribution
My contribution to this project was focused on:
- Feature extraction and feature selection
- Training and evaluation of machine learning models
- Performance analysis using AUC, Precision, Recall and F1-score

## Data
Due to data confidentiality and ethical constraints, the original dataset is not included in this repository.
The provided code focuses on the machine learning pipeline and can be adapted to similar datasets.

## Methods
- Feature extraction from cognitive assessment data
- Models tested: Logistic Regression, SVM, Random Forest
- Evaluation metrics: AUC ≈ 0.80, Precision/Recall/F1 ≈ 0.75

## Repository Structure
- `src/` – feature extraction and model evaluation code
- `notebooks/` – exploratory analysis and result visualization
